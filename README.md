## Selected projects

### ⚽ [Anfield Matchday Intelligence](https://github.com/Thizisfranklin/Anfield-Stadium-Ticket-Value-Revenue)
**[Explore the interactive website ↗](https://thizisfranklin.github.io/Anfield-Stadium-Ticket-Value-Revenue/)**

A project close to home as a Liverpool supporter: if match access is in demand, why do some allocated tickets still go unused? I analyzed public ticketing reports, compared seasons carefully, tested forecasting against simple baselines, and built an interactive decision-support experience. The limits of the public data are part of the story.

### 🕸️ [FraudGraph](https://github.com/Thizisfranklin/FraudGraph)
Can transaction relationships reveal illicit activity that individual Bitcoin transactions miss? I compared transaction-only and graph-enhanced models on the Elliptic++ network, using chronological evaluation and limited analyst-review scenarios. Network features helped in one experiment, but their advantage narrowed with richer transaction data—and performance deteriorated in later periods.

### 📊 [Retail Marketing Intelligence](https://github.com/Thizisfranklin/Retail-Promotion-Targeting-Uplift-Modeling)
**[Explore the interactive dashboard ↗](https://retail-promotion-targeting-uplift-modeling-jdjd8epuvzztn6kxjpe.streamlit.app/)**

Using a randomized email campaign, I measured incremental purchases and explored whether uplift modeling could improve customer targeting. Both campaigns had positive average effects; the held-out analysis didn't establish that the targeting model beat random selection.

### 🏟️ [Touchline Signal](https://github.com/Thizisfranklin/touchline-signal)
**[Explore the football intelligence website ↗](https://thizisfranklin.github.io/touchline-signal/)**

An independent Premier League and La Liga briefing platform that combines validated match data, team preferences, explainable ranking, and source-linked football updates. Built with a Python ingestion pipeline and a React/TypeScript interface; the public site uses scheduled, read-only data snapshots rather than claiming live scores or deployed AI personalization.
